Agent Skill 评价与改进

已验证的优点

  • 无固定 topic 时仍发现 7 个共同核心主题。
  • 覆盖高音、舌位、混声、修音、模仿、漏气和职业用嗓。
  • 能生成标题、Hook、高光语句、编辑描述与风险标签。
  • 语义重合率 70%，说明核心发现具备一定稳定性。

当前缺口

  • Terra 11 条归并成 9 个 topic，存在两组重复。
  • Sol 9 条归并成 8 个 topic，也存在一组重复。
  • 3 个边缘 topic 只被一方发现。
  • Terra 有一次跨候选引语错配。
  • 模型自评分不能直接替代统一阈值。

正确的改进方式：保持自由发现

  1. 每个 Agent 先独立建立本视频的 topic inventory，再自由选择高光；不由外部固定 topic。
  2. 每条已选内容必须说明相对已有 topic 的新增信息，降低同义重复。
  3. 默认每个语义 topic 只保留一个最佳片段；确需两个时说明内容增量。
  4. 高光语句附候选 ID 和证据范围，由系统做确定性文本对齐。
  5. 分开评估 topic 发现、片段选择、脚本质量和风险判断。
  6. 盲审继续做语义归并，不要求 topic 名称字面一致。

下一轮基准应覆盖访谈、带货、知识讲解和娱乐直播，并重复多次，报告语义 Jaccard、单向覆盖率、重复率、证据对齐率和盲审质量分。
