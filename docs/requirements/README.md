# Development requirement format

Create one Markdown file per loop-engineering run. Include:

- the user-visible outcome;
- current behavior and evidence;
- in-scope and explicit non-goals;
- architecture, security, compatibility and data constraints;
- observable acceptance criteria;
- required artifact or visual inspection evidence;
- recovery and rollout expectations.

Do not include credentials, private transcripts, model session IDs, generated commands or local media.
