# Clip Profile: mini_lesson

- 合法时长为 90--300 秒，目标约 180 秒；90 秒与 300 秒边界均合法。
- 内容单位是一个中心教学目标，可包含定义、步骤、解释、示范、纠错、练习和结论。
- “单一话题”指一个中心教学目标，不是只能有一个微观点，也不是若干同领域内容的拼接。
- 仍应选择最短完整连续边界，不为了接近 300 秒扩大，不用直播互动或无关内容补足 90 秒。
- 极短感谢或自然停顿可判 minor/nonblocking；销售、求赞、设备调试、排课、无关聊天、回答
  另一个问题等实质中断必须 blocking，并通过重定边界、自然子单元或拒绝解决。
- 超过 300 秒不得机械切割。只可输出具有独立问题、解释和结论的自然教学子单元；否则记录
  `topic_too_long_without_natural_split`。
