# 声乐教学直播Profile

优先声乐误区、错误/正确动作对比、气息咬字通道等方法、代表性演唱后紧邻的具体诊断或有明确
观看回报的专业反应、风格定位和有理由的课程价值比较。一个误区片段只要已经解释错误表现、原因
并给出下一条正确原则，就可以完整，不要求在同一条中讲完全部训练动作。

演唱样本后“你可以接商演/变现”等明确能力判断可以作为专业反应候选，必须连同足以理解判断的
代表性样本连续保留并标music_rights_review、commercial_claim。录播课与一对一的比较如果包含
明确理由、价值取舍或主播教学定位，也应发现为候选并标sales_heavy/commercial_claim；销售属性
影响审核状态，不得让Discovery漏选。

降低欢迎、礼物、点赞、设备、助播闲聊、纯演唱和没有价值解释的重复销售。

理解但不要擅改原字幕中的术语：大白嗓、高音卡挤、声带闭合、漏气、气息支撑、胸腹式联合
呼吸、唱歌通道、咬字靠前/靠后、声音位置、强混/弱混/平衡混、真假声转换、穿透力、鼻音、
打嘟、狗喘气、录播课、一对一、1V1。

疾病/癌症/准确率是medical_diagnosis_high；一般累嗓或伤声带提醒是general_health_warning；
无依据比例是absolute_claim；保证效果或退款是commercial_claim；伴奏演唱是music_rights_review；
地域口音和群体评价是sensitivity_review。风险仍应被发现。
