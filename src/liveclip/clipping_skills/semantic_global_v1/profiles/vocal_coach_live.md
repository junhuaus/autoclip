# Vocal coach live profile

适用于声乐老师直播、助播互动、观众连麦演唱、现场点评和课程介绍。

优先识别声乐误区纠正、错误与正确动作对比、气息/咬字/通道/位置等可操作方法、代表性
演唱后的具体诊断、样本与诊断的因果关系、风格定位建议、边界清晰的专业观点，以及能解释
教学价值和主播定位的品牌内容。

完成 topic map 和 Global 覆盖审计时，逐类回看以下高价值家族；这是召回清单，不是关键词
匹配、数量配额或降低阈值的理由。每一类只有形成独立 viewer_promise、完整 payoff 和运行时
合规连续区间时才返回：

- 概念或误区纠正，以及错误动作、正确动作、声带/气流反应之间的因果演示；
- 代表性演唱或发声样本后，对闭合、漏气、穿透力、鼻音、咬字、通道或位置作具体诊断；
- 诊断之后给出的练习、修正动作、风格路线或适配边界；
- 基于实际演唱能力给出的职业可能性、市场定位或变现判断及其理由；
- 对天赋、学习路径、录播、一对一或其他课程形式的价值比较、适用人群和代价；
- 能独立解释教学方法、服务差异或主播专业定位的品牌观点，而非只有价格和催单。

同一位连麦者中，“声音问题诊断”“风格路线建议”“市场或变现判断”可能是三个不同承诺；
只有共享同一论证和 payoff 时才合并。地域、商业、健康或版权风险只改变 review_status，不得
把整段连麦降为 low 或 no_candidate。

默认拒绝调灯/机位/暖气/关门、连续欢迎、点赞/关注/灯牌、念用户名、礼物感谢、无关助播
打趣、年龄外貌闲聊、重复直播话术、只有价格的销售、过长纯演唱和被更强切片覆盖的理论。
连麦诊断优先形成连续的“12–25 秒代表性演唱 → 1–2 个核心问题 → 原因 → 改进方向”；
风格定位优先形成“学员困惑 → 音色/习惯分析 → 不建议方向 → 推荐方向”。不得跳剪拼接。

以下内容即使不是分步骤教程，也具有潜在的普遍观看价值，Discovery 必须先发现再交给 Global
Review 评分：

- 初学者询问是否需要天赋，老师给出明确结论、理由或自身可验证经历；
- 代表性演唱后紧接漏气、穿透力、鼻音、咬字、通道或位置的具体诊断与改进方向；
- 演唱后对风格路线、职业可能性或市场定位给出有依据的判断；
- 对录播、一对一或其他学习方式作有理由的价值取舍，而不只是报价格。

这些片段若包含伴奏、绝对化成功率、商业承诺或地域表达，仍返回候选并进入相应风险审核。
长演唱不要求从第一句开始：优先选择诊断前最后 12–25 秒、足以让陌生观众听出老师所评问题的
连续代表性样本。这个范围只是软偏好，不是固定裁切规则；证据充分性决定最短代表性样本，
最终完整片段仍服从运行时时长。课程内容只有价格和催单时仍是噪声；但若明确比较学习效果、个性化程度、
适用人群或代价，则先按消费者决策/品牌观点评估其内容价值，再标 commercial_claim 或
absolute_claim。

声乐教学经常用阶段对照、错误/正确动作对照或“样本 → 原因 → 调整”兑现一个承诺。若标题或
问题承诺比较多个阶段或动作，候选必须包含每个被承诺部分及统一结论；不能把互补的半答案
拆成两条，也不能把新练习、销售或互动当成旧承诺的必要结尾。相邻内容只有在各自提出独立
问题并各有 payoff 时才拆开。

编号训练路线必须在所选范围内直接提出全部项目，并到最后一项所需解释第一次完成处结束。
不要求回到直播最早的零散铺垫：如果老师稍后重新完整列出全部项目并继续解释难点或关系，
这个重述是更短边界的有效候选。更早的课程铺垫和更晚的课时、价格、销售不是编号方法的一部分；
只在片尾念一遍项目名称，仍不能代替被剪掉的必要解释。
声乐路线“概览”和每一步的完整训练课不是同一 viewer_promise。概览若已列全步骤、说明顺序与
重点，并对最难或最关键部分给出解释，可以独立成立；不得要求它收进此前所有动作示范。标题与
payoff 必须忠实写成概览，不能宣称片段已逐项教会观众。

误区、诊断或动作演示一旦已经给出原因和可识别结论，随后预告的另一项演示或新问题属于新的
viewer_promise。应在旧承诺第一个自然结束 cue 停止，不得因后续内容尚未完成而删除或拉长
已经闭合的片段。

领域词汇仅用于理解和可选规范化，不得无依据改写原字幕：大白嗓、高音卡挤、高音破音、
声带闭合、漏气、气息支撑、胸腹式联合呼吸、唱歌通道、咬字靠前、咬字靠后、声音位置、
头腔、胸腔、强混、弱混、平衡混、真假声转换、穿透力、鼻音、打嘟、狗喘气、小狗哈气、
录播课、一对一、1V1。

风险标记使用结构化 risks：根据声音判断疾病、准确率、癌症/息肉/手术等诊断使用
medical_diagnosis_high，并必须人工审核；一般“唱法不当可能累嗓子或伤声带”使用
general_health_warning，不得自动升级为医学诊断；无依据百分比或绝对成功率用 absolute_claim；
退款/保证进步用 commercial_claim；带伴奏翻唱用 music_rights_review；地域口音、外貌或职业
评价用 sensitivity_review。风险内容仍应被 Discovery 发现，Global Review 再独立决定
editorial_decision 和 review_status。内容类型比例只是软偏好，不得降低质量标准。

只有原片自身在解释、质疑或纠正医学主张时，才能把它命名为“为什么要谨慎”“误区”或
“风险”。主播单方面宣称听声诊病、准确率或癌症案例时，风险标签不能替代内容 payoff，也
不能用批判性标题把宣传包装成科普；没有其他独立价值时直接 drop。

风险标签必须精确：大白嗓、声带闭合、漏气、声音位置、通道等正常声乐术语和动作讲解本身
不是 medical_diagnosis_high；只有疾病、癌症或医学诊断才使用 medical_diagnosis_high，一般
护嗓或伤声带提醒使用 general_health_warning。技术评价
“大白嗓”本身不是 sensitivity_review；只有地域口音、外貌或职业等容易形成刻板印象的评价
才使用 sensitivity_review。
